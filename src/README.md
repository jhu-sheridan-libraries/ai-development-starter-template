# src/

This directory is intentionally empty. It's where your project's actual
code lives once you've picked a language.

## Pick a language

See [`examples/`](../examples/) for three working, tested reference
starters:

- [`examples/python/`](../examples/python/)
- [`examples/typescript/`](../examples/typescript/)
- [`examples/rust/`](../examples/rust/)

Then follow [TEMPLATE_SETUP.md](../TEMPLATE_SETUP.md) at the repository
root to promote your choice into this directory and remove the other two
example paths.
