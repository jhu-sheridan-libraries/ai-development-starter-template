# Citations and attribution

## How to cite this work

This repository includes a [`CITATION.cff`](./CITATION.cff) file, which
GitHub uses to render a "Cite this repository" widget and which citation
managers (Zotero, EndNote, etc.) can import directly. Fill it in with your
project's actual title, authors, and repository URL.

If you publish a paper, dataset, or report describing this project, add
that citation here as well, for example:

```
Lastname, F. (2026). Project Title. Journal/Venue.
DOI or URL.
```

## Getting a DOI (archiving on Zenodo)

This repository also ships `.zenodo.json` and `ro-crate-metadata.json`,
which together with `CITATION.cff` let you archive a citable, versioned
snapshot on [Zenodo](https://zenodo.org/) with a real DOI whenever you cut
a GitHub release. See
[`docs/archiving-and-citability.md`](./docs/archiving-and-citability.md)
for the full setup steps. Once you have a DOI, add it here, to
`CITATION.cff`'s `identifiers` field, and as a badge in `README.md`.
